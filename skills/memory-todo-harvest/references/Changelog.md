# 版本史

## 1.1.2 版本发布（2026-09-13）

- 修复改过待办文字后，原来勾的完成状态会丢失、已忽略的条目又重新冒出来的问题
- 修复待办正文里写了目录路径时，条目可能被分到同名项目下的问题
- 整理使用说明：操作步骤与常见错误前置，判定原理收进参考文件

## 1.1.1 版本发布（2026-09-12）

- 安装后的目录更干净：说明文档统一收敛到技能主文档与参考文件
- 支持来源改用不带产品指向的表述，同一套配置在不同环境里都读得通

## 1.1.0 版本发布（2026-09-12）

- 新增可视化待办清单页面：归集后自动生成，按项目分组、可筛选、可折叠，离线可看、可直接分享
- 新增勾选写回：页面勾选后导出结果写回，完成状态会被记住；取消勾选也能撤销
- 新增「只要数据不要页面」的运行方式

## 1.0.1 版本发布（2026-09-11）

- 触发词改为用户会真实说出口的短短语（待办散落在各处、提取待办、统一清单、属于哪个项目…）
- 新增触发词评估集，用于校验触发精准度
- 「不触发」场景独立成节，与触发词分开

## 1.0.0 版本发布（2026-09-11）

首个版本。

- 归集口径：只认三类显式待办信号（待办章节 / 未勾选 checkbox / 行内待办句）；
  指令与规则文件只取显式标记，不把章节正文整段当待办
- 覆盖多家 agent 的记忆目录与项目指令文件，可混在一张清单里
- 归属补全：每条待办标出所属项目与事由；分不清归属的诚实留「未分类」，不硬塞
- 误收可撤回：机器新提名的条目先待确认，确认或忽略的判定另存、不随数据重建丢失
- 配置驱动，纯标准库单脚本，支持预览与抽样核准
